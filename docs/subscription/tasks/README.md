# Subscription Tasks

This folder contains the task list for implementing the new subscription and billing model.

## How to Use
- Each phase file (`phase-*.md`) lists concrete tasks.
- Check off items as you complete them.
- Ensure `flutter analyze` and related unit/tests pass before moving to the next phase.

## Phase Overview
- **Phase 1**: Core subscription provider setup and entitlement notifier.
- **Phase 2**: Pricing tier integration and backend API updates.
- **Phase 3**: Front‑end UI changes (subscription screen, billing support screen).
- **Phase 4**: Cross‑platform payment integration (Apple, Google Play, Paddle).
- **Phase 5**: Webhooks, entitlement caching, and admin tools.
- **Phase 6**: Regression testing, QA gates, and release preparation.

See the individual phase files for the detailed task checklist.
