# M-21 — Discord community server

> Added by the pre-release audit (2026-11-20). Back to the [index](README.md).

**Source:** owner request in the 1.0 pre-release audit; `docs/community-plan.md`
(proposal list, nothing promoted).
**Why only you:** the server, its moderation and its invite link are yours.

Nothing in the app or website links to Discord today, so 1.0 can ship
without it. If you want it at launch:

1. Create the server (channels: announcements, help, feature-requests,
   per-tool: jenkins, github-actions, sonarqube) with community rules and
   AutoMod on; turn on Community mode and a rules screen.
2. Create a permanent invite link that does not expire.
3. Tell me the link; I'll add it to the website's support page and the
   app's Support screen behind one config value, with a test, and update
   the store text's support URL if you want it there.

**Evidence:** the invite link opens the server from a fresh account.
