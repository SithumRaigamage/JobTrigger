Features

Run, watch and fix builds from anywhere.

Everything here ships in the current app. Nothing on this page is a promise.

Trigger any job, with the right inputs

Browse folders and multibranch pipelines, then start a build. Every parameter type gets a proper input — choices, booleans, multi-line text, files — and secret parameters stay masked and are never saved.

  • ✓Search the job tree, even offline
  • ✓Replay a build with the same parameters
  • ✓Approve pipeline input steps

Console logs that keep up

The log streams while the build runs, with colours, search and per-stage views. Save the full log or share it with your team in two taps.

See why a build failed

Pipeline stages, test results, the commits that went in, artifacts, and what triggered it — on one screen. History and trends show whether it is getting worse.

Stop refreshing

Watch a build and get a notification when it finishes. Pin the jobs you care about and see their status on a home-screen widget.

And the rest

Many servers

Add work and personal Jenkins servers and switch between them.

GitHub Actions

Browse your repositories and workflows next to Jenkins.

Nodes and queue

See what is waiting, which agents are busy, and take a node offline.

App lock

Face ID or fingerprint, with your device passcode as backup.

Open Jenkins links

Paste a job or build link from chat and jump straight to it.

Light and dark

Follows your phone's theme, readable in both.
