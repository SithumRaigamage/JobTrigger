# Website design v2 — REJECTED (2026-10-24)

**Status:** Rejected. Kept for reference only. Don't build from it.

**Reason:** the colours and theme don't match the JobTrigger app. v2 swung
too far away from the app's identity: paper white `#F6F5F1` and black
backgrounds, a signal-orange `#FF5A1F` accent, sharp 4px corners with hard
offset shadows, and Bricolage Grotesque / IBM Plex type. It read as a
different product.

**Lesson from v1 + v2 together:** v1 copied the app's screens too literally;
v2 abandoned the app's brand. The next version must keep the app's brand
(its colours and theme) while still looking like a marketing website rather
than app screens.

**What it covered:** the same pages and stories as
[v1](../v1-app-look/README.md#what-it-covered), with the same file names.
