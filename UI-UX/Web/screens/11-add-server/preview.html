How do I get this?

Getting a Jenkins API token

  1. 1 Open Jenkins and sign in.
  2. 2 Click your name (top right), then Security.
  3. 3 Under API Token, click Add new token and name it "JobTrigger".
  4. 4 Click Generate and copy it. Jenkins shows it only once.

Use an API token, not your password — it works with single sign-on and you can revoke it on its own.
